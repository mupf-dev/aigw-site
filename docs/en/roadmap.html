Status in November 2026#

ai-gw has been public since November 2026. The planned feature set of the first version 0.1 is implemented and tested: data plane with OpenAI and Anthropic input, all listed providers, routing and resilience, tenants, limits and budgets, a plugin chain with guardrails, response cache, MCP gateway, admin API and admin UI, GitOps, observability, SQLite and Postgres, container image for amd64 and arm64. Since then, WASM plugins with signatures, tool inventory and tool policies, further guardrails (prompt-leak, link-guard, language, invisible characters), guardrail profiles, Microsoft Entra ID in many places and workload/agent identities have been added, among others. The full changelog is in the repository.

No release yet. There is no published version and no ready-made container images yet; you build from source. Until 1.0, configuration, manifest format (aigw/v1alpha1) and admin API may change incompatibly between minor versions.

Until the first release#

  • Release 0.1.0 with ready-made container images for amd64 and arm64.
  • Legal confirmation of the license of the embedded tokenizer tables (MIT); they can already be switched off.
  • A security policy and a confidential reporting channel in the repository.

Afterwards#

Topics marked as open or “later” in the concept documents – in no fixed order:

  • MCP server for administration, generated from the OpenAPI specification, so that admin API, UI and MCP are on par.
  • MCP gateway: sessions across multiple instances, resumption of SSE streams, OAuth to the upstream, grants at resource and prompt level, the plugin chain on tool arguments and results.
  • WASM plugins: keyless signatures with a transparency log in addition to own keys, four-eyes approval, more host functions, asynchronous execution.
  • Performance: a faster stream path (fewer small allocations per chunk), batched counter calls for Redis, the request-log writer on its own core.
  • Logs: an optional backend for very large log volumes.
  • Embedding in platforms: ai-gw is API-first, a single binary and declaratively configured so that platforms can embed it – for example BYOC (Build Your Own Cloud), whose service catalog includes an AI gateway.

Wishes and priorities from practice are welcome: Contribute.

ai-gw (AI-Gateway) – Open-source, self-hosted AI gateway in Rust – one endpoint for many AI providers. One binary for gateway, admin API and admin UI.
